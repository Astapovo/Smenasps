# 🚀 SmenaSps v1.1.0 — Релиз с автообновлением из Справки и контролем установки PWA

Официальный релиз автономного инженерного терминала и оперативного журнала смены **SmenaSps v1.1.0** для репозитория [Astapovo/Smenasps](https://github.com/Astapovo/Smenasps).

---

## ✨ Что нового в версии v1.1.0

1. **Автоматическая проверка новых версий при открытии Справки (`?`)**:
   - При каждом открытии окна **Справка (`?`)** (или по нажатию `Alt + H`) приложение автоматически опрашивает **GitHub Releases API** (`https://api.github.com/repos/Astapovo/Smenasps/releases/latest`), файл `version.json` и проверяет обновления `Service Worker`.
   - Если в репозитории опубликован новый релиз, в верхней части Справки появляется сигнальный баннер с номером новой версии, датой публикации, списком изменений и кнопкой **«Обновить приложение до vX.Y.Z»**.
   - На кнопке `?` в верхней шапке загорается пульсирующий индикатор при наличии доступного обновления.
   - Обновление выполняется в 1 клик: активируется новый `Service Worker`, очищается кэш старой оболочки (`CacheStorage`) и перезагружается актуальная версия **без потери локальных записей журнала, чек-листов и настроек в `localStorage`**.

2. **Железное скрытие кнопки и раздела «Установить PWA» после установки**:
   - Плитка в Настройках, кнопка в быстром всплывающем меню, мини-иконка навигации и карточка `Установка приложения на устройство (PWA)` теперь скрываются на трёх уровнях одновременно:
     - через мгновенную проверку в `<head>` до первого рендера (`data-pwa-installed="true"`);
     - через CSS `@media (display-mode: standalone)`, `window-controls-overlay`, `fullscreen`, `minimal-ui`;
     - через события `appinstalled`, `matchMedia('change')`, `navigator.getInstalledRelatedApps()` и постоянный флаг `smenasps_pwa_installed`.
   - Добавлена защита от прямого перехода в категорию `pwa_install`, если приложение уже установлено.

3. **Быстрая выгрузка в локальный Excel (шаблон 11 колонок) и единый `Code.gs`**:
   - Прямое копирование таблицы смены или всего журнала в буфер обмена (`Ctrl+V` в Excel) и скачивание `.CSV` строго по шаблону из 11 колонок (`Дата ДД.ММ.ГГГГ | Начало | Окончание | Простой ЧЧ:ММ | Оборудование | Зона | Узел | Описание | ФИО | Статус | Код`).
   - В `Code.gs` добавлены поддержка даты завершения сбоя (`dateEnd`), синхронизация мульти-чеклистов обхода, настраиваемых уровней сбоя и автоформирование листа `Экспорт_Excel`.

4. **Автоматизация релизов на GitHub (`.github/workflows/release.yml`)**:
   - Добавлен GitHub Actions workflow для автоматической упаковки архива релиза и публикации в разделе **GitHub Releases** при пуше тега `v*` или запуске вручную из вкладки **Actions**.

---

## 📦 Файлы релиза

- `SmenaSps_v1.1.0_GitHub_Release.zip` — полный архив для загрузки в репозиторий [Astapovo/Smenasps](https://github.com/Astapovo/Smenasps).
- `index.html` — самодостаточное приложение SmenaSps v1.1.0.
- `Code.gs` — серверный скрипт для Google Таблицы (1-RTT Delta Sync + Мульти-чеклисты + Экспорт Excel).
- `version.json` — манифест версии для системы автообновления.

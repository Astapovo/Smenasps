# SmenaSps v1.3.8 — Оперативный журнал смены, чек-листы обхода и База Знаний АСУ ТП / КИПиА

Автономное веб-приложение (Offline-First PWA) для дежурных инженеров АСУ ТП и КИПиА.

## Ключевые особенности v1.3.8
- **Локальный вход в `Админ (ROOT)` (защита от случайного нажатия)**: пароль по умолчанию `root` или `1234` (меняется во вкладке `Админ (ROOT) → Демо-режим и безопасность`). Открывается мгновенно офлайн и онлайн.
- **Простая облачная синхронизация через Google Таблицы (`Code.gs`)**: скрипт работает от имени разработчика (`Запуск от имени: Я`, `Доступ: Все`) без серверных паролей, токенов и настройки `Script Properties`.
- **Отдельное поле «Примечание» и выгрузка в Excel (12 колонок)**: прямое копирование (`Ctrl+V`), экспорт в `.CSV` и автоматический лист `Экспорт_Excel` в Google Таблице.
- **Сгруппированная панель ROOT**: конструкторы мульти-чеклистов обхода, уровней сбоя, дерево связей, справочники зон/узлов/шаблонов/инженеров и разделы Базы Знаний.
- **Устойчивый офлайн-режим PWA (`sw.js`)**: кэширование стартовой страницы и справочников для мгновенного запуска без сети.

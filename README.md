**SmenaSps** — автономное прогрессивное веб-приложение (Offline-First PWA) для оперативного ведения сменного журнала, фиксации сбоев и простоев оборудования, проведения регламентных сменных обходов (чек-листов), ведения технической базы знаний и передачи смен.

Приложение работает полностью автономно без платных серверов и внешних СУБД, используя локальное хранилище браузера и бесплатную многопользовательскую дельта-синхронизацию через **Google Таблицы (Google Apps Script)** с поддержкой выгрузки в локальный **Microsoft Excel (`.xlsx` / `.csv`)**.

---

## 🎯 Основные возможности SmenaSps v1.0

### 1. Оперативный журнал сбоев и Сигнальная башня (Andon)
- **Живой индикатор состояния объекта (Andon Tower)** в шапке приложения:
  - 🟢 **Зелёный** — штатная работа без открытых замечаний;
  - 🟠 **Янтарный** — есть узлы в ожидании ЗИП или подрядчика;
  - 🔴 **Красный (пульсирующий)** — имеются активные не устранённые сбои «В работе».
- **Выбор даты и времени начала и устранения сбоя**: при регистрации и закрытии сбоя указывается как **Дата сбоя**, так и **Дата устранения** (по умолчанию подставляется актуальная текущая дата). Время простоя в минутах автоматически рассчитывается с учётом многосуточных интервалов и переходов через полночь.
- **Гибкая система «Уровень сбоя» (по умолчанию выключена)**:
  - По умолчанию уровни сбоя скрыты, чтобы не перегружать карточку.
  - В меню `Настройки → Уровни сбоя` функцию можно включить в 1 клик, а также добавить свои уровни, переименовать кнопки, изменить описание или число полосок индикатора (от 1 до 3).
- **Шкала времени смены (Shift Timeline)**: наглядная диаграмма всех событий за текущую 12-часовую смену.
- **Копирование карточки в 1 тап**: клик по коду инцидента копирует готовый отчёт для вставки в Telegram, WhatsApp или рабочий мессенджер.

### 2. Конструктор чек-листов («Регламентный сменный обход»)
- **Как это работает**:
  1. Во вкладке **«Смена»** расположен сворачиваемый блок **«Регламентный сменный обход»** с живым счётчиком (`X из Y выполнено`) и прогресс-баром (`0–100%`).
  2. По ходу осмотра дежурный отмечает проверенные пункты. Состояние отметок мгновенно сохраняется в памяти устройства.
  3. По завершении обхода нажатие кнопки **«Отчёт в журнал сбоев»** автоматически формирует итоговую запись в журнале смены с количеством проверенных пунктов и временем осмотра.
- **Полная настройка чек-листа без правки кода**:
  - Откройте **«Настройки» → значок «Чек-лист обхода»** (или нажмите кнопку **«Настроить чек-лист»** прямо внутри обхода во вкладке «Смена»).
  - Доступно **добавление новых пунктов** (название проверки + норматив/пояснение), **редактирование** существующих пунктов, **изменение порядка следования** кнопками `↑` / `↓`, **удаление** пунктов, **переименование заголовка** самого обхода, а также **полное скрытие/включение** блока обхода.
  - Все изменения чек-листа автоматически синхронизируются между устройствами через лист `Справочник_Чеклисты` в Google Таблице.

### 3. Меню «Настройки» с раскрытием значков и адаптацией под ПК и смартфоны
- При нажатии на кнопку **«Настройки»** в панели навигации раскрывается **панель со значками разделов** (*Профиль и шапка*, *Уровни сбоя*, *Чек-лист обхода*, *Тема и экран*, *Звук и вибро*, *Демо и PWA*, *Админ ROOT*).
- При выборе любого значка открывается окно, содержащее **только выбранный раздел настроек** (с кнопкой возврата «← Все значки настроек» и панелью быстрого переключения).
- **Настройка ширины экрана на ПК**: в разделе `Настройки → Тема и экран` можно выбрать ширину рабочей области для монитора ПК: *Средняя (1024px)*, *Широкая (1360px, по умолчанию)* или *Во весь экран (100%)*.

### 4. Персонализация: 6 Цветовых тем и Haptic & Audio Engine 2.0
- 6 цветовых палитр в разделе `Настройки → Тема и экран`: **Авто (По смене)**, **Светлая (Цех)**, **Тёмная (Андон)**, **Кибер-Схема**, **Изумруд** и **Янтарный монитор**.
- Встроенный синтезатор звукового и виброотклика (Web Audio API + Vibration API), работающий на 100% без интернета и внешних аудиофайлов.

### 5. Встроенный Справочный центр (`Help`) и Обучающий демо-режим
- Кнопка **`?` (Справка)** в шапке открывает подробное руководство по всем функциям, настройке Google Таблиц, переносу в Excel и горячим клавишам.
- Для быстрого знакомства приложение предзаполнено **обучающими демо-данными**, которые очищаются одной кнопкой **«Очистить учебные записи (Чистый старт)»** в разделе `Настройки → Демо и PWA`.

## ⚙️ Что необходимо для корректной работы приложения

1. **Поддерживаемые устройства и браузеры**:
   - Любой современный браузер (Google Chrome, Microsoft Edge, Яндекс.Браузер, Safari, Firefox) на Android, iOS, Windows, Linux или macOS.
2. **Протокол HTTPS (или `localhost`) для работы офлайн (PWA)**:
   - Для автоматического кэширования через `Service Worker (sw.js)` и установки иконки приложения на главный экран смартфона/ПК сайт должен открываться по `HTTPS` (при публикации на **GitHub Pages** протокол HTTPS предоставляется автоматически и бесплатно).
   - При открытии локального файла `index.html` напрямую с диска (`file:///...`) весь интерфейс, журнал и база знаний работают штатно, но для установки PWA рекомендуется GitHub Pages или локальный веб-сервер.
3. **Разрешённое локальное хранилище (`localStorage`)**:
   - В браузере не должен использоваться режим «Инкогнито / Частный доступ» при постоянной работе, чтобы браузер не сбрасывал локальный кэш при закрытии вкладки.
4. **Корректные права доступа в Google Apps Script (при использовании облака)**:
   - При публикации скрипта `Code.gs` в Google Таблице обязательно укажите: **Запуск от имени: «Я» (Me)** и **У кого есть доступ: «Все» (Anyone)**. Это позволяет смартфонам дежурных синхронизироваться в фоновом режиме за 1 запрос без ошибок CORS и без ввода паролей Google.

## ☁️ Настройка интеграции с Google Таблицами

1. Создайте новую пустую Google Таблицу на Google Диске (например, `SmenaSps — Облачный Журнал Смены`).
2. Откройте в верхнем меню таблицы: **Расширения → Apps Script**.
3. Полностью замените код в редакторе на содержимое файла **`Code.gs`** из этого репозитория (или скопируйте его внутри приложения: `Настройки → Админ (ROOT) → Единый скрипт Code.gs`) и нажмите `Ctrl + S`.
4. Нажмите **Развернуть (Deploy) → Новое развертывание (New deployment)**, выберите тип **Веб-приложение (Web app)**:
   - **Запуск от имени**: `Я (Me)`
   - **У кого есть доступ**: `Все (Anyone)`
5. Скопируйте полученный URL (заканчивается на `/exec`), откройте в приложении `Настройки → Админ (ROOT)` (пароль по умолчанию: `root` или `1234`), вставьте адрес, нажмите **«Сохранить адрес»**, а затем **«Выгрузить справочники»**.
6. Скрипт автоматически создаст все 11 рабочих листов (`Журнал`, `Смена_Сообщения`, `Практические_решения`, `Служебный_Мета`, `Справочник_Зоны`, `Справочник_Оборудование`, `Справочник_Инженеры`, `Справочник_Шаблоны`, `Справочник_Чеклисты`, `Справочник_РазделыБЗ`, `Справочник_БазаЗнаний`).

## 📊 Как копировать и переносить данные из Google Таблицы в локальную таблицу Excel (`.xlsx`)

Вы можете переносить данные сменного журнала в локальный Microsoft Excel любым из 4 удобных способов:

### Способ 1. Скачивание готовой книги Microsoft Excel (`.xlsx`) со всеми листами
1. Откройте вашу Google Таблицу в браузере.
2. В верхнем меню выберите **Файл → Скачать → Microsoft Excel (.xlsx)**.
3. На компьютер скачается полноценная книга Excel со всеми вкладками (`Журнал`, `Смена_Сообщения`, `Практические_решения` и всеми справочниками).

### Способ 2. Прямое копирование строк через буфер обмена в открытый локальный файл Excel
1. Откройте лист `Журнал` в Google Таблице, выделите нужные строки (или весь лист комбинацией `Ctrl + A`) и нажмите `Ctrl + C`.
2. Откройте вашу локальную таблицу Excel, поставьте курсор в нужную ячейку и выполните **Специальная вставка → Значения** (`Ctrl + Shift + V`).
3. *Защита дат и времени:* благодаря встроенной функции `sanitizeDateOrTime` в `Code.gs`, все даты (`ГГГГ-ММ-ДД`) и время (`ЧЧ:ММ`) сохраняются в строковом формате и **не превращаются** в `30.12.1899` при переносе в локальный Excel.

### Способ 3. Живая автоматическая подгрузка из Google Таблицы в локальный Excel (через Power Query)
Если вы хотите, чтобы локальный файл Excel на вашем ПК сам обновлял данные из Google Таблицы в 1 клик:
1. В Google Таблице нажмите кнопку **Настройки доступа (Share)** и выберите **«Все, у кого есть ссылка — Читатель»**.
2. Скопируйте идентификатор вашей таблицы (`ID_ТАБЛИЦЫ`) из адресной строки браузера (`https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/edit`).
3. В локальном Microsoft Excel откройте вкладку **Данные → Получить данные → Из других источников → Из Интернета (From Web)**.
4. Вставьте прямую ссылку на экспорт потока `.xlsx`:
   ```text
   https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/export?format=xlsx
   ```
5. Выберите лист `Журнал` и нажмите **Загрузить**. Теперь при нажатии кнопки **«Обновить всё»** в локальном Excel таблица будет автоматически подтягивать все свежие записи из облака!

### Способ 4. Мгновенная выгрузка в Excel (`.csv`) прямо из приложения SmenaSps
1. Откройте в приложении вкладку **«Отчёты»**.
2. Нажмите **«Журнал в CSV»**.
3. Приложение сформирует файл с маркером `UTF-8 BOM` и разделителем точка с запятой (`;`), который открывается двойным кликом в русскоязычном Microsoft Excel с правильной кодировкой и разбитыми по столбцам данными.

## 🚀 Развёртывание на GitHub Pages (за 2 минуты)

1. Создайте новый публичный репозиторий на GitHub (например, `smenasps`).
2. Загрузите в корень репозитория файлы из архива релиза: `index.html`, `Code.gs`, `SmenaSps_Master_Database.json`, `manifest.json`, `sw.js`, `README.md`, `LICENSE` и папку `icons/`.
3. Перейдите в **Settings → Pages**, в блоке **Build and deployment** выберите ветку `main` / папка `/(root)` и нажмите **Save**.
4. Через 1 минуту приложение будет доступно по адресу `https://<ваш-логин>.github.io/smenasps/`.

- В меню **«Настройки»** для инженеров оставлены только базовые разделы: **Профиль и шапка**, **Тема и экран**, **Звук и вибро**, **Установить PWA** (отображается только если приложение ещё не установлено на устройство) и **Админ (ROOT)**.
- Все административные конструкторы и сервисные функции (**Чек-листы обхода**, **Уровни сбоя**, **Демо-база и доступ**) вынесены внутрь защищённого раздела **Админ (ROOT)** (пароль по умолчанию: `root`).
- **Мульти-чеклисты с облачной синхронизацией**: администратор может создавать неограниченное количество различных чек-листов (например, *«Приём смены и регламентный обход»*, *«Проверка контура безопасности и блокировок LOTO»*, *«Еженедельный осмотр шкафов»*), переименовывать или удалять их, а также добавлять, редактировать и менять порядок пунктов (`↑`/`↓`). При сохранении все чек-листы автоматически выгружаются в лист `Справочник_Чеклисты` (с колонкой `Название чек-листа`) в Google Таблице и синхронизируются на устройствах всех сменных специалистов.

# Подробная инструкция для автора: Размещение, настройка и развитие проекта SmenaSps v1.0

Сергей, ниже собрано полное описание финальной версии **SmenaSps v1.0**: что изменено, как устроены новые функции (конструктор чек-листов обхода, значки категорий настроек, расширенный экран для ПК, перенос из Google Таблиц в локальный Excel), и что необходимо для публикации на GitHub и стабильной работы.

## 1. Ключевые обновления версии SmenaSps v1.0

* **Новое название `SmenaSps` (версия `v1.0`)**:

  * Название приложения, шапка, манифест `manifest.json`, `sw.js`, `Code.gs`, мастер-база `SmenaSps_Master_Database.json`, префиксы локального хранилища (`smenasps_*`) и все иконки (`icons/*`) переведены на бренд **SmenaSps v1.0**.

* **Убраны кнопки выбора темы из шапки и из окна `Help`**:

  * В верхней шапке и в нижней панели окна Справки (`Help`) больше нет кнопок переключения темы — смена цветовой палитры и ширины экрана ПК сосредоточена в специализированном разделе `Настройки → Тема и экран`.

* **Раскрытие значков при нажатии на «Настройки» и изолированный показ раздела**:

  * При нажатии на кнопку **«Настройки»** в навигационной панели всплывает компактное меню из **7 значков разделов**:

    1. 👤 **Профиль и шапка**

    2. 🎚️ **Уровни сбоя** *(по умолчанию выключены, с редактором пунктов)*

    3. ✅ **Чек-лист обхода** *(полный конструктор регламентного сменного обхода)*

    4. 🎨 **Тема и экран** *(6 цветовых тем + выбор ширины экрана на ПК: 1024px / 1360px / 100%)*

    5. 🔊 **Звук и вибро** *(Haptics 2.0 и синтезатор щелчков Web Audio)*

    6. 🎓 **Демо и PWA** *(очистка учебных записей «Чистый старт» и установка на устройство)*

    7. 🔐 **Админ (ROOT)** *(интеграция с Google Таблицей, справочники зон/узлов/шаблонов и сборка автономного `index.html`)*

  * При нажатии на любой значок открывается окно, содержащее **только выбранную категорию настроек** (все остальные разделы скрыты), с кнопкой возврата **«← Все значки настроек»** и быстрой полосой мини-иконок вверху.

* **Конструктор чек-листов («Регламентный сменный обход»)**:

  * Вынесен в отдельный значок настроек **«Чек-лист обхода»** (а также доступен по кнопке **«Настроить чек-лист»** прямо внутри аккордеона обхода во вкладке «Смена»).

  * Позволяет: добавлять новые пункты проверки (заголовок + норматив/пояснение), редактировать существующие пункты, менять их порядок стрелками `↑` и `↓`, удалять пункты, менять заголовок самого обхода или полностью скрывать блок обхода со вкладки «Смена».

* **Выбор «Даты устранения» (по умолчанию — актуальная дата)**:

  * В формах регистрации/редактирования сбоя и быстрого закрытия («Меры и статус») добавлено поле **«Дата устранения»**, которое по умолчанию подставляет текущую дату и точно рассчитывает простой даже при переходе сбоя через полночь или на следующие сутки.

## 2. Как копировать данные из Google Таблицы в локальную таблицу Excel (`.xlsx`)

Эта инструкция уже встроена прямо внутрь приложения (в окно настройки `Code.gs` и во вкладку `Help → Google Таблицы`), а также добавлена в `README.md`:

1. **Скачать готовую книгу Excel (`.xlsx`) со всеми вкладками**:

   * В открытой Google Таблице выберите **Файл → Скачать → Microsoft Excel (.xlsx)**. Вы получите готовый локальный файл Excel со всеми листами (`Журнал`, `Смена_Сообщения`, `Практические_решения`, `Справочник_*`).

2. **Скопировать строки через буфер обмена в открытый локальный файл Excel**:

   * На листе `Журнал` в Google Таблице выделите нужные строки (или нажмите `Ctrl + A`), скопируйте (`Ctrl + C`) и в локальном файле Excel вставьте через **Специальная вставка → Значения** (`Ctrl + Shift + V`). Благодаря экранированию `sanitizeDateOrTime` в `Code.gs` даты и время переносятся без искажения в `30.12.1899`.

3. **Настроить живую связь локального Excel с Google Таблицей (через Power Query)**:

   * В Google Таблице откройте доступ *«Все, у кого есть ссылка — Читатель»*.

   * В локальном Excel выберите **Данные → Получить данные → Из других источников → Из Интернета** и вставьте ссылку:
     `https://docs.google.com/spreadsheets/d/ВАШ_ID_ТАБЛИЦЫ/export?format=xlsx`

   * Теперь по нажатию кнопки **«Обновить всё»** в локальном Excel таблица сама подтянет все новые записи из Google Таблицы.

4. **Выгрузить CSV напрямую из приложения SmenaSps**:

   * Во вкладке **«Отчёты»** нажмите **«Журнал в CSV»** — скачается файл с кодировкой `UTF-8 BOM` и разделителем `;`, который сразу открывается в русскоязычном Excel.

## 3. Что нужно для корректной работы приложения (Технический чек-лист)

1. **Хостинг с HTTPS (GitHub Pages)**:

   * Для работы офлайн-кэша (`sw.js`) и кнопки установки приложения на телефон/ПК (`manifest.json`) разместите файлы из архива `SmenaSps_v1.0_GitHub_Release.zip` на **GitHub Pages** (`Settings → Pages → Branch: main / root`). GitHub автоматически выдаст `HTTPS`-ссылку.

2. **Параметры развёртывания `Code.gs` в Google Таблице**:

   * При развёртывании скрипта (`Расширения → Apps Script → Развернуть → Новое развертывание → Веб-приложение`) обязательно выбирайте:

     * *Запуск от имени*: **Я (Me)**

     * *У кого есть доступ*: **Все (Anyone)**

   * После сохранения URL `.../exec` в разделе `Настройки → Админ (ROOT)` нажмите кнопку **«Выгрузить справочники»**, чтобы скрипт создал все 11 листов в таблице.

3. **Подготовка собственной преднастроенной сборки**:

   * Настройте свои зоны, оборудование, сотрудников и чек-лист обхода, нажмите **«Очистить учебные записи (Чистый старт)»**, а затем в разделе `Админ (ROOT) → Перенос одним файлом` нажмите **«Собрать автономный index.html»**. Полученный файл можно загрузить в свой репозиторий на GitHub, чтобы у всех коллег сразу открывалась ваша рабочая конфигурация.

## Обновление структуры Настроек и Админ-панели (ROOT) в v1.0
- **Чистое меню настроек**: в плитках настроек оставлены только `Профиль и шапка`, `Тема и экран`, `Звук и вибро`, `Установить PWA` (автоматически скрывается, когда приложение уже установлено как PWA) и `Админ (ROOT)`.
- **Единый центр управления в `Админ (ROOT)`**: управление **Уровнями сбоя**, **Мульти-чеклистами обхода** и **Демо-базой** доступно только после входа под паролем `root`.
- **Мульти-чеклисты через Google Таблицы**: в `Админ (ROOT) → Чек-листы` можно создавать сколько угодно отдельных чек-листов. Все они сохраняются в лист `Справочник_Чеклисты` (столбец D — название чек-листа) и автоматически передаются всем пользователям при синхронизации.
